# История христианских доктрин · History of Christian Doctrine

Одностраничный сайт о развитии двенадцати христианских учений от апостольского века до XX столетия. Главное измерение – учение, а не эпоха: на линии каждого учения видно, как оно формулировалось, оспаривалось и уточнялось.

Адрес: https://deoleg.github.io/doctrines/. Сайт также открыт вкладкой **Doctrines** в `admin.html`.

## Экраны

| Маршрут | Что показывает |
|---|---|
| `#/` | Матрица «учение × эпоха»: точки записей, размер по важности, флажок смежных учений |
| `#doctrine/<id>` | Линия учения: обзор, ключевые повороты, вертикальная хронология со связями (`?s=1` – со смежными записями) |
| `#timeline?d=…&t=…&e=…&i=…&s=1&q=…` | Общая хронология с фильтрами по учению, типу, эпохе, важности и с поиском |
| `#item/<id>` | Карточка записи поверх текущего экрана |
| `#glossary`, `#glossary/<id>` | Глоссарий с алфавитным указателем и поиском |
| `#about` | О проекте и источниках |

Язык задаётся переключателем RU/EN или параметром `?lang=en`. Тема по умолчанию следует настройке системы, её можно переключить вручную. Выбранные язык и тема сохраняются в `localStorage`; без него сайт тоже работает.

## Откуда данные

Все сведения взяты из девяти учебников, перечисленных в `meta.books` файла данных: Холл, Пеликан (тт. 1–2), Беркхоф, Гонсалес (однотомник и т. III), МакГрат, Лейн, Гренц и Олсон. Примечание об источниках (`meta.note_ru`) показано на экране «О проекте». Номера страниц – страницы PDF-файлов. Расхождения книг в датах приведены в примечаниях к датам записей.

## Запуск локально

Через `file://` сайт не работает: браузер не загружает модули и данные. Нужен локальный сервер:

```sh
python3 -m http.server 8000   # в корне репозитория
```

Затем откройте http://localhost:8000/doctrines/.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root. Шага сборки нет, все пути относительные. Сайт появится по адресу `/doctrines/`.

После правок в CSS или JS обновите версии файлов, иначе браузеры могут до 10 минут отдавать старые копии из кэша:

```sh
python3 scripts/bump_asset_versions.py
```

Модули версионируются через import map в `index.html`. Скрипт сам переписывает `?v=` по хешу содержимого.

## Проверка

```sh
node scripts/test_doctrines.mjs   # нужен Node 22+ и Google Chrome
```

Тест поднимает статический сервер и проверяет сайт в headless Chrome:

- матрица и хронология показывают все записи;
- фильтры и поиск работают на обоих языках, включая «ё» = «е» и греческий;
- открывается каждая ссылка: `#item`, `#doctrine`, `#glossary`, прямые и обратные связи, ключевые повороты;
- работают язык, тема и режим без `localStorage`;
- на 375 и 360 px нет горизонтальной прокрутки;
- работает клавиатура: Tab, Enter, Esc;
- при открытии через `file://` показывается сообщение;
- файл данных после теста не изменён.

Те же проверки запускает GitHub Actions (`.github/workflows/test-doctrines.yml`).

## Устройство

```
doctrines/
  index.html            разметка-каркас, import map, ранний скрипт темы
  css/style.css         токены цветов (в т. ч. --doc-<id> для обеих тем), вёрстка
  js/app.js             загрузка данных, роутер, панель карточки, язык и тема
  js/i18n.js            словарь интерфейса RU/EN
  js/util.js            индексы, нормализация для поиска, DOM-помощники
  js/views/*.js         матрица, линия учения, хронология, карточка, глоссарий, о проекте
  data/doctrines.json   данные (не редактировать вручную)
```

Текст из данных вставляется только через `textContent` и текстовые узлы, `innerHTML` не используется.

## Данные: `data/doctrines.json`

Файл генерируется вне сайта и вручную не редактируется.

- `meta.eras` – 8 эпох по порядку (`id`, `from`, `to`, `ru`, `en`). Это столбцы матрицы.
- `meta.doctrines` – 12 учений (`overview_*`, `turning_points` – id записей). Это строки матрицы.
- `meta.types`, `meta.books` – типы записей и учебники.
- `meta.glossary` – термины (`term_*`, `original`, `meaning_*`, `items` – id записей).
- `items` – записи, отсортированные по `year_start`, `year_end`:
  - основные поля: `era`, `doctrine`, `doctrines_secondary`, `type`, `importance` (1–3), заголовок, описание, `date_label_*`, `date_note_*`;
  - содержание: `positions`, `key_terms` (`glossary_id`), `key_points_*`, `people_*`, `texts_*`, `outcome_*`, `place_*`;
  - `related` – направленные связи `response-to | develops | rejects | leads-to`; обратные связи сайт вычисляет сам;
  - `sources` – книга и страницы.

У каждого поля `_ru` есть парное `_en`. Пустые поля на сайте не показываются.
